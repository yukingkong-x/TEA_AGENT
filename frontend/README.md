## 你管什么 / 不管什么

- **管**：`frontend/` 目录里的所有代码
- **不管**：`backend/`、`firmware/`——它们的接口没好之前，你按 PRD 里写的字段结构造**假数据**先开发，别停下来等

## 技术栈与环境准备（一次性，10 分钟）

| 要装          | 说明        |
| ------------- | ----------- |
| Node.js ≥ 20 | 官网 LTS 版 |
| VSCode + Git  | 全队一致    |

```bash
cd frontend
npm install
npm run dev        # 起在 http://localhost:5173
```

技术栈（已锁定，别换）：React 18 + Vite + TypeScript + Tailwind CSS + React Flow（画布）+ ECharts（图表）。
