### 1) `agents/base.py`：把「说了要动手」钉成真 tool_call（这是唯一还缺的硬约束）

```python
# 模块级
IRRIGATE_RE = re.compile(r"irrigate", re.IGNORECASE)
REQUIRED_TOOL: dict[str, str] = {"decision": "create_task"}   # 需要真的调工具的 Agent

# AgentRunner.run() 里，6 轮循环结束后、parse_sections 之前加一行：
        await self._enforce_required_tool(turn, messages, tools)

# 方法
    async def _enforce_required_tool(self, turn, messages, tools) -> None:
        want = REQUIRED_TOOL.get(self.agent_key)
        if not want or turn.degraded:
            return
        if any(r.get("name") == want and r.get("status") == "executed" for r in turn.tool_calls):
            return
        if self.agent_key == "decision" and not IRRIGATE_RE.search(turn.content or ""):
            return
        result = await self.llm.complete(
            messages + [
                {"role": "assistant", "content": turn.content or ""},
                {"role": "user", "content": (
                    f"你刚才只在正文里描述了 {want} 的调用，但没有真正发出 tool_call，"
                    f"平台侧没有产生任何任务。请立刻调用 {want} 完成下单。")},
            ],
            tools=[s for s in tools if s.get("function", {}).get("name") == want],
            temperature=self.spec.temperature,
            tool_choice={"type": "function", "function": {"name": want}},
        )
        for tc in result.tool_calls:
            record, _ = await self._execute_tool(tc)
            turn.tool_calls.append(record)
```

    def _patch_task_no(turn) -> None:

### 3) `core/llm.py`：`tool_choice` 透传 + 429 退避（补丁已生成）

`docs/handoff/llm_tool_choice_ratelimit.patch`（`git apply` 即可）。要点：
- `complete(..., tool_choice=None)`，只在 `tools` 非空时传；
