# 硬件实测日志（队友 C 每天记）

方案书里"真实数据"的来源，也是答辩时证明"我们真的跑过硬件"的证据。

**格式**：`日期 ｜ 板子 ｜ 实测读数（土壤湿度 / 空气温湿度 / 光照，写实际数字）｜ 问题与备注`

**要求**：

1. 每天至少一行，当天的事当天记；
2. 读数必须是板上实测，**不许编**；
3. 首次通电、首次浇水、土壤标定（干/湿基准）这几个关键节点必须单独记一行。
