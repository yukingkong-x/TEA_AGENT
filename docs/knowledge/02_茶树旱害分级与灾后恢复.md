# 茶树旱害分级与灾后恢复

> 适用场景：连续高温少雨、土壤含水率持续走低时的风险评估与补救建议。
> 来源：中国农业科学院《极端高温干旱气候茶园减灾和恢复技术措施》（茶叶产业专家团）；中国农业科学院茶叶研究所茶叶种植中心公开访谈。

## 1. 茶树的温度与水分耐受

- 气温升至 **38℃** 时对茶树已不友好；若 38℃ 以上**持续一周左右**，茶树会出现不同程度的损害。
- 昼夜温差是缓冲因素：白天 40℃、夜间降到 30℃ 上下，茶树仍有喘息空间；若夜温也居高不下，受害显著加重。
- 新建茶园、立地条件差、建于阳坡的茶园最易整株死亡。

## 2. 受害程度分级与措施

| 程度 | 表征 | 管理原则 | 修剪 |
| --- | --- | --- | --- |
| 轻度 | 部分叶片变黄绿、出现褐斑、轻度卷曲变形 | 顶部枝条未枯死，让茶树自行发芽恢复 | 不修剪 |
| 中度 | 多数成熟叶红褐、萎蔫、枯焦脱落，顶端芽梢未完全枯死 | 同上，加强肥水促进恢复 | 不修剪 |
| 重度 | 老叶嫩叶枯焦脱落、形成光杆枝、多数枝条枯死，主干未死 | 及时修剪，促发新枝 | 蓬面轻修剪，去除受损枝叶 |
| 极度 | 整体缺水、根毛死亡、叶片全落、侧枝与主干枯死 | 彻底深翻、加培客土，消除土壤障碍后重新建园 | 重新种植 |

要点：**只有重度以上才修剪**。轻中度修剪反而会消耗本已紧张的养分，延缓恢复。

## 3. 灾后恢复的顺序

1. **先救水，再施肥**：土壤含水率恢复到 60% 以上再考虑追肥，干旱期施肥易烧根。
2. **轻修剪**：剪去焦枯枝叶，避免其诱发病虫害并遮挡下方枝条发芽。
3. **叶面补养**：可喷施 0.3%~0.5% 磷酸二氢钾 + 0.5%~1% 尿素，增强细胞渗透压、减少蒸腾。叶面肥喷后需保留 7 天以上采摘间隔期。
4. **树冠培养**：恢复期以养树冠为主，暂缓采摘，第二年枝条转壮后品质不受影响。

## 4. 对品质的影响

受旱胁迫后恢复生长的枝条偏细、芽头偏小；茶树胁迫期内茶多酚、类黄酮等保护性成分上升，成茶苦涩味会加重。通过后期科学养护把树冠培养起来，次年采摘品质可恢复正常。

## 5. 预警口径（供智能体引用）

- 连续 7 天日最高气温 ≥ 35℃ 且土壤含水率 < 55%：发布**中度干旱预警**，建议启动灌溉。
- 土壤含水率 < 40% 或已出现成片叶片焦枯：发布**重度预警**，灌溉 + 遮阴 + 暂停采摘。
- 高温期灌溉窗口限定在夜间与清晨，白天禁止喷灌。
