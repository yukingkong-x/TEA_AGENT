# 茶园主要虫害：假眼小绿叶蝉与茶尺蠖

> 适用场景：巡园发现叶部异常、虫口上升时的识别与防治建议。
> 来源：整理自中国农业科学院茶叶研究所茶树病虫害研究方向公开资料、《中国茶叶》期刊科普文章与全国农技推广服务中心茶园病虫害防治指导意见。

## 1. 假眼小绿叶蝉

**识别**
- 成虫体长 3~4mm，黄绿色，前翅近透明，头部有一对假单眼（白色小圆点），善跳跃。
- 若虫无翅，黄绿色，多栖息在**芽叶背面**和嫩茎上。
- 被害状：芽叶叶尖、叶缘先红褐焦枯（俗称"焦边"），随后芽叶卷曲、硬化，生长点停滞；严重时新梢不发、产量骤降。

**发生规律（长江中下游茶区）**
- 年发生 **9~11 代**，世代重叠严重，华南茶区代数更多。
- 两个主高峰：**5 月下旬—6 月**（夏茶前）与 **9~10 月**（秋茶期）。
- 高温干旱年份虫口上升快；多雨年份相对受抑。成虫在茶树或杂草上越冬。

**防治**
1. **农业防治**：分批勤采，及时摘除带卵与若虫的嫩梢，是最经济的压虫手段；清除茶园周边杂草，减少越冬与转移寄主。
2. **物理防治**：每亩悬挂黄色粘虫板 20~25 片，挂于蓬面上方 10~15cm，定期更换。
3. **药剂防治**：达到防治指标后用药（参考当地植保部门发布的指标，一般夏茶百叶虫量 6~10 头）。可选茚虫威、虫螨腈、联苯菊酯等，注意轮换以延缓抗性。
4. **安全间隔期**：喷药后必须遵守产品标注的安全间隔期（一般 7~10 天）才能采摘，严禁边喷边采。

## 2. 茶尺蠖

**识别**
- 成虫灰褐色蛾子；幼虫体色随环境变化（灰褐、黄绿等），**第二腹节背面有十字形黑纹**，受惊时直立如小枝。
- 低龄幼虫啃食叶肉留表皮，形成透明枯斑；**4 龄后暴食**，可将蓬面叶片吃光，仅剩秃枝（俗称"光头茶"）。

**发生规律**
- 长江中下游年发生 **6~7 代**，以蛹在茶树根际土中越冬。
- 各代幼虫盛发期大致在 4 月、6 月、7 月、8 月、9 月，**7~8 月高温期**为害最重。
- 成虫有趋光性，夜间活动。

**防治**
1. **灯光与性诱**：成虫期用杀虫灯或性诱捕器，压低虫口基数。
2. **人工防治**：结合冬耕挖蛹，减少越冬蛹；幼龄幼虫期人工捕捉。
3. **生物防治**：选用 Bt 制剂、茶尺蠖核型多角体病毒等，对天敌友好。
4. **药剂防治**：**3 龄前**是防治适期（4 龄后抗药性显著增强），可选联苯菊酯、茚虫威等，重点喷施蓬面与叶背。
5. 连片茶园应**统一防治**，否则相邻地块相互迁移，防效难以维持。

## 3. 共同注意事项

- 优先采用采摘、诱杀、生物制剂等非化学手段，化学农药只在达到防治指标时使用。
- 严禁使用国家明令禁止在茶树上使用的高毒农药；出口茶园需对照进口国残留限量。
- 施药器械用后清洗，包装物回收，不得随意丢弃于茶园。
- 喷药选择无风阴天或傍晚，避免高温强光时段与采茶时段重叠。
