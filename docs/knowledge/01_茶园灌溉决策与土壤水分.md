# 茶园灌溉决策与土壤水分管理

> 适用场景：智能灌溉决策、土壤含水率阈值判定、灌溉方式选择。
> 来源：中国农业科学院茶叶研究所《茶叶生产全程质量控制技术规范》编制说明（2024）；中国农业科学院《极端高温干旱气候茶园减灾和恢复技术措施》；国家茶叶产业技术体系《茶园春旱应对技术》。

## 1. 什么时候需要灌溉

茶树喜湿怕涝，根系活动层（0~40cm）的土壤相对含水量是灌溉决策的核心指标。

- **灌溉阈值**：当茶园土壤含水率**低于 70%**（占田间持水量的百分比）且旱情持续时，应及时灌溉，满足茶树对水分的需要，保证茶树正常生长。
- **高温叠加判定**：夏季气温达到 35℃、日平均气温接近 30℃、日平均水面蒸发量达到 9mm，且上述条件**持续一周以上**、土壤含水量低于田间持水量的 70% 时，必须立即开始灌溉。
- **不宜灌溉的情形**：土壤含水率已高于 80% 时继续灌溉会造成根系缺氧、烂根，并加剧养分淋失。雨天、土壤积水、叶片有露水时不宜喷灌。

## 2. 不同含水率区间的处置建议

| 土壤相对含水量 | 判定 | 处置 |
| --- | --- | --- |
| ≥ 80% | 偏湿 | 停止灌溉，注意排水防涝 |
| 65% ~ 80% | 适宜 | 正常管理，无需灌溉 |
| 55% ~ 65% | 轻度缺水 | 安排灌溉，单次补至 65% 左右 |
| 40% ~ 55% | 中度缺水 | 立即灌溉，优先滴灌补水 |
| < 40% | 重度缺水 | 立即灌溉并检查旱害，必要时遮阴 |

生产上常把 55%~65% 作为灌溉的目标区间：低于 55% 触发灌溉，补到 65% 左右停水，既满足茶树需要又避免过量。

## 3. 灌溉方式

- **滴灌**：最节水，水分直接进入根层，不湿润叶面，不易诱发叶部病害，适合坡地与缺水茶园，是首选方式。
- **微喷灌**：降温效果优于滴灌，高温干旱期可用于茶园小气候调节，但会湿润叶面，连续阴雨时慎用。
- **带状喷灌**：适合成片平整茶园，覆盖均匀但耗水量大。
- 一般建议采用滴灌、微喷和带状喷灌等**节水灌溉**措施，并结合茶行铺草、覆盖等措施提高灌溉效率。避免大水漫灌，漫灌易造成土壤板结与养分流失。

## 4. 灌溉时间与用量

- **时间**：高温季节应选择**清晨或夜间（22:00—次日 3:00）**灌溉。白天烈日下喷水会使茶树上烤下蒸、湿热交加，受害反而加重。
- **单次用量**：以湿润耕作层 **10~20cm** 土壤为宜，避免一次灌透造成深层渗漏。
- **灌溉后复测**：灌溉结束需等待水分下渗与土壤渗透平衡（一般 30~90 分钟）后再复测土壤含水率，刚停水时的读数偏低且跳动大，不能作为效果判定依据。

## 5. 与覆盖、遮阴的配合

- 茶行间铺草（稻草、修剪枝叶）厚度约 9cm，可显著减少土壤水分蒸发，是成本最低的抗旱措施。
- 遮阳网与茶树蓬面距离应保持在 50cm 以上，切勿直接覆盖蓬面，否则会加重危害。
- 间作绿肥可遮阴降温、改善茶园小气候。

## 6. 决策口径（供智能体引用）

1. 读取最近 3 条土壤含水率读数，取中位数作为当前值，避免单点异常值主导决策。
2. 当前值 < 55% 且未来 24 小时无有效降雨 → 建议灌溉；55%~65% → 观察，不作业；> 65% → 不必灌溉。
3. 灌溉时长按「补至 65%」估算，单次不宜超过 30 分钟，超过则分次执行。
4. 灌溉后必须复测，用复测值与灌溉前基线的差值计算达成率。
