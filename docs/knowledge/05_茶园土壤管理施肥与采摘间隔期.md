# 茶园土壤管理、施肥与采摘间隔期

> 适用场景：土壤 pH 异常、树势衰弱、施肥方案与采摘安全间隔期咨询。
> 来源：《茶叶生产全程质量控制技术规范》编制说明（中国农业科学院茶叶研究所，2024）；NY/T 496《肥料合理使用准则 通则》。

## 1. 土壤条件

- **pH**：茶树适宜 **4.5~6.0**，最适 5.0~5.5。pH > 6.5 时根系吸收受阻、叶片黄化；pH < 4.0 时铝锰活化、根系中毒。
- **改良**：酸度过高施白云石粉或石灰调节；偏碱地块需施硫磺粉并结合增施有机肥。
- **肥力监测**：按测土配方施肥要求，**至少每 2 年**检测一次土壤肥力（pH、有机质、碱解氮、有效磷、速效钾）。
- **耕作**：根据土壤状况与树势采取深耕（20~30cm，结合施基肥）、中耕（5~10cm，除草松土）、浅耕；坡地可免耕以防侵蚀。
- **保土蓄水**：茶行铺草、修剪枝叶还园、秸秆覆盖，既保墒又增肥；覆盖材料不得受污染。

## 2. 施肥原则

- 坚持**科学用肥**：基肥与追肥配合，以**有机肥为主、有机无机结合**，避免单一施肥导致养分失衡。
- 按 NY/T 496 执行；禁止使用工业垃圾、医院垃圾、生活垃圾制成的肥料，以及重金属、抗生素超标的畜禽粪便。
- 畜禽粪便必须**无害化处理**后施用，防止寄生虫卵与病菌污染。
- 常用氮磷钾比例约为 2:1:1（按纯养分计），具体依产量目标、树龄与土壤检测结果调整。

## 3. 施肥时期

| 时期 | 时间 | 内容 |
| --- | --- | --- |
| 基肥 | 10 月下旬—11 月 | 菜饼/商品有机肥 + 复合肥，开沟深施 20cm 左右 |
| 催芽肥 | 2 月（春茶开采前 30~40 天） | 以氮为主 |
| 夏茶追肥 | 5 月中下旬 | 氮钾配合 |
| 秋茶追肥 | 7 月上中旬 | 氮钾配合，配施磷肥 |
| 叶面肥 | 需肥关键期或受旱后 | 0.3%~0.5% 磷酸二氢钾 + 0.5%~1% 尿素 |

## 4. 采摘间隔期与质量安全

- **叶面肥喷施后**须按说明书保留采摘间隔期，一般 **7 天以上**，以产品标签为准。
- **农药**按标签安全间隔期执行，茶园常用药剂多为 7~14 天；出口茶园还需对照进口国残留限量。
- 施药、施肥器械与运输工具用后及时清洗；肥料包装袋回收清理，不得丢弃于茶园。
- 名优茶手工采"一芽一叶初展"，大宗茶可机采；开采前确认已过所有投入品的安全间隔期。

## 5. 决策口径（供智能体引用）

- 土壤 pH 低于 4.5 或高于 6.5 → 建议先改良土壤再谈施肥增产。
- 施肥建议必须带**安全间隔期**提醒，不得给出"立即采摘"的建议。
- 缺肥判断以"土壤检测 + 树势 + 叶色"三者结合，单看叶色易与病害、旱害混淆。
