# 茶园主要病害：炭疽病与根腐病

> 适用场景：连续阴雨、高湿环境下叶部病斑与整株萎蔫的诊断。
> 来源：整理自中国农业科学院茶叶研究所病害研究方向公开资料与全国农技推广服务中心茶园病害防治指导意见。

## 1. 茶炭疽病

**症状识别**
- 多从**成叶叶尖、叶缘**开始，初为水渍状暗绿色小点，后扩大为不规则形褐色病斑。
- 病斑边缘有明显的深褐色隆起线，与健部分界清楚；后期病斑中央灰白色，散生**黑色小粒点**（分生孢子盘），常呈轮纹状排列。
- 潮湿时病斑表面可见粉红色黏质孢子堆。病叶易脆裂、脱落，严重时蓬面光秃。

**发病条件**
- 病菌在病叶中越冬，靠雨水飞溅传播。
- **高温高湿**是主因：气温 **25~28℃**、相对湿度 **80% 以上**、连续阴雨 4~7 天，病害迅速流行。
- 偏施氮肥、蓬面郁闭、通风不良、排水不畅的茶园发病重；台刈后新梢期最易感病。

**防治**
1. **农业防治**：及时摘除并销毁病叶；清沟排水，降低园内湿度；增施磷钾肥、控制氮肥，提高叶片抗性；合理修剪保持蓬面通风。
2. **药剂防治**：发病初期喷施苯醚甲环唑、吡唑醚菌酯、多菌灵等，7~10 天一次，连续 2~3 次，注意轮换用药。
3. **安全间隔期**：按产品标签执行（一般 7~14 天），采摘前严格停药。

## 2. 茶根腐病（含茶苗根腐、褐根病）

**症状识别**
- 地上部分：发芽迟缓、新梢细弱、叶片变黄或突然萎蔫青枯，**白天萎蔫、夜间恢复**是典型早期信号。
- 地下部分：根系皮层变褐、腐朽，须根大量脱落；扒开根际土壤可见白色或褐色菌丝。
- 剖开茎基部可见维管束变褐。

**发病条件**
- 土壤长期积水、排水不良、地下水位高是首要诱因。
- 连作苗圃、土壤偏酸过甚（pH < 4.0）、土传病原积累的田块发病重。

**防治**
1. **以防为主**：建园时起垄种植、开深沟排水，避免低洼积水地块；苗圃实行轮作。
2. **拔除病株**：发现病株连同根际土壤一并挖除，病穴撒生石灰消毒，2 年以上再补植。
3. **药剂灌根**：发病初期用恶霉灵、甲霜灵等灌根，每株灌足量药液。
4. **改土**：增施有机肥与生物菌肥，改善土壤通透性；酸度过高时适量施白云石粉调节。

## 3. 病害与灌溉决策的联动规则（供智能体引用）

- 土壤含水率 > 80% 且预报连续降雨 2 天以上 → **不建议灌溉**，同时提示根腐病风险。
- 连续阴雨 4 天以上、气温 25~28℃ → 提示**炭疽病高发窗口**，建议巡园复查叶部病斑。
- 叶片已出现病斑且需灌溉时，优先选择**滴灌**（不湿润叶面），避免喷灌加速孢子传播。
- 发病期灌溉应安排在上午，使叶面在入夜前干燥。
